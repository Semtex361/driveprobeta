V90.6 – ZUSÄTZLICHE SYNCHRONISATIONS-SICHERHEIT

Kontrolliert und behoben:
1. Fahrschüler-Änderungen -> Cloud
2. Neue Fahrschüler -> Cloud
3. Fahrstunden neu/bearbeitet -> Cloud
4. Fahrstunden gelöscht -> Cloud
5. Fahrstunden verschoben -> Cloud (zusätzlich behoben)
6. Ausbildungsstand/Notizen -> Cloud
7. Unterschrift -> Cloud (zusätzlich behoben)
8. Andere Geräte bekommen Änderungen per Supabase Realtime
9. Nach Internet-Unterbrechung wird automatisch erneut synchronisiert
10. Beim Zurückkehren zum Tab wird automatisch ein Cloud-Abgleich gemacht
11. Beim Reconnect wird der Realtime-Kanal neu aufgebaut
12. Lokales Backup bleibt als Sicherheitsnetz erhalten

Damit ist die frühere Situation "auf Gerät 2 erst nach Reload sichtbar"
nicht mehr der normale Synchronisationsweg. Ein Reload ist nicht mehr erforderlich.

Wichtig:
ENABLE_REALTIME.sql einmal im Supabase SQL Editor ausführen und prüfen,
dass students, lessons und training_progress in supabase_realtime erscheinen.
