DRIVEPRO BETA – GITHUB PAGES

1. Lade ALLE Dateien dieses Ordners direkt in dein GitHub-Repository hoch.
2. index.html muss direkt im Hauptverzeichnis liegen.
3. In GitHub: Settings → Pages
4. Source: Deploy from a branch
5. Branch: main
6. Folder: / (root)
7. Save
8. Warte einige Minuten.

Die GitHub-Pages-Adresse hat dieses Format:
https://DEIN-GITHUB-NAME.github.io/DEIN-REPOSITORY-NAME/

Danach die Adresse auf dem iPhone in Safari öffnen:
Teilen → Zum Home-Bildschirm → DrivePro Beta.

Hinweis: GitHub Pages ist öffentlich. Keine echten Fahrschülerdaten in diese öffentliche Beta-Version eintragen.
